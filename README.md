# 🍽️ Rawabi – Online Restaurant Management System

## Project Overview

Rawabi is an ongoing online restaurant management project designed to provide customers with a convenient platform to explore restaurant menus and place food orders online.

The project aims to simplify restaurant operations through an integrated online ordering and management system.

## Planned Features

- 🍴 Restaurant menu and food categories
- 🛒 Online food ordering
- 👤 Customer registration and login
- 💳 Online payment integration
- 📊 Admin dashboard
- 📦 Order management

## Technologies

- Python
- SQL
- HTML
- CSS

## Development Approach

This project is being developed as a practical learning experience with AI-assisted development.

It helps me explore web development, database management, Python programming, and online business systems.

## Project Status

🚧 Work in Progress

Features are being developed and tested progressively.

## Project Goals

- Build a functional online restaurant platform
- Understand database integration
- Learn application development using Python and SQL
- Explore restaurant order management systems
